# معمار - MiMaar

تطبيق متكامل للمعماريين على iOS و Android مبني بـ **Flutter**.

## المميزات

### 1. البورتفوليو
- عرض مشاريع المعماري في شبكة أنيقة مع فلاتر حسب التصنيف (فيلا / شقة / مكتب / تجاري)
- إضافة / تعديل / حذف مشاريع مع صور من معرض الصور
- حفظ المشاريع المفضلة

### 2. متابعة مشاريع العملاء
- إدارة المشاريع مع بيانات العميل ورقم الهاتف (اتصال مباشر)
- مراحل المشروع: استفسار ← تصميم مبدئي ← اعتماد ← تنفيذ ← مراجعة ← تسليم
- نسبة إنجاز قابلة للتعديل + قائمة مهام مع أولويات + ملاحظات

### 3. الاستوديو (أداة الرسم والقياس)
- رسم جدران وغرف على لوحة بها شبكة قياس
- أداة قياس المسافات بوحدات حقيقية (متر / سم) مع مقياس قابل للتعديل
- تحديد العناصر ونقلها + تراجع + حذف + حفظ اسكتشات

### 4. المجتمع
- منشورات مع صور + إعجابات + تعليقات
- قائمة معماريين مع متابعة / إلغاء متابعة

## البيانات

التطبيق يعمل **بدون إنترنت** - البيانات محفوظة محلياً على الجهاز عبر **Hive**،
مع بيانات تجريبية تُضاف تلقائياً عند أول تشغيل. البنية جاهزة للربط لاحقاً
بسيرفر (Firebase / Supabase / REST API).

## التشغيل على جهازك

```bash
flutter pub get
flutter run          # على جهاز متصل أو محاكي
```

الاختبارات والتحليل:

```bash
flutter analyze
flutter test
```

## بناء iOS بدون جهاز Mac

نظراً لأن بناء iOS يحتاج Xcode (متوفر على Mac فقط)، استخدم **Codemagic**:

1. ارفع الكود إلى GitHub/GitLab
2. سجّل في [codemagic.io](https://codemagic.io) واربط المستودع
3. ملف `codemagic.yaml` المرفق جاهز - اضغط Build
4. لرفع التطبيق على App Store، فعّل Signing في إعدادات Codemagic وأضف
   شهادة Apple Developer + ملف الـ Provisioning

## بنية المشروع

```
lib/
├── main.dart                 # نقطة التشغيل + تهيئة Hive
├── app.dart                  # جذر التطبيق + Providers
├── theme/                    # الثيم والألوان (وضع عربي RTL)
├── models/                   # النماذج (مشاريع، منشورات، اسكتشات...)
├── data/                     # Hive + بيانات تجريبية
├── state/                    # مخازن الحالة (Provider)
├── screens/
│   ├── portfolio/            # البورتفوليو
│   ├── projects/             # مشاريع العملاء
│   ├── studio/               # أداة الرسم والقياس
│   └── social/               # المجتمع
├── widgets/                  # مكونات مشتركة
└── utils/                    # دوال مساعدة (تنسيق الوقت والأرقام)
```

## إضافة الخدمات السحابية لاحقاً
